# Majestic Plumbing

**Enterprise Company Profile Website**
Built with modern web technologies to deliver performance, scalability, and maintainability.

🌐 **Live Website**: [https://majestic-plumbing.vercel.app/](https://majestic-plumbing.vercel.app/)

---

## 📌 Overview

Majestic Plumbing is a professional **company profile website** developed for an Australian plumbing business. The project focuses on:

* Clean and professional UI
* High performance and SEO readiness
* Scalable and maintainable architecture
* Enterprise‑grade frontend standards

This repository contains the complete source code for the website.

---

## 🛠 Tech Stack

This project uses a modern and battle‑tested frontend stack:

* **Next.js (Latest / App Router)** – React framework for production‑ready applications
* **TypeScript** – Type‑safe development
* **Tailwind CSS** – Utility‑first styling
* **shadcn/ui** – Accessible, customizable UI components
* **Vercel** – Deployment and hosting platform

## ✨ Features

## 🚀 Getting Started

### Prerequisites

Make sure you have one of the following installed:

* Node.js 18+
* npm / yarn / pnpm / bun

---

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/majestic-plumbing.git
cd majestic-plumbing
```

Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

---

### Development

Run the development server:

```bash
npm run dev
```

Open your browser and navigate to:

```
http://localhost:3000
```

The application supports hot reload for faster development.

---

## 🏗 Build for Production

```bash
npm run build
npm run start
```

---

## 🌍 Deployment

The project is deployed using **Vercel**.

To deploy your own version:

1. Push the repository to GitHub
2. Connect it to Vercel
3. Deploy with default Next.js settings

📖 Documentation: [https://nextjs.org/docs/app/building-your-application/deploying](https://nextjs.org/docs/app/building-your-application/deploying)

---

## 🧩 Customization

* Company content can be modified via components inside `components/`
* Images and icons can be replaced in `public/`
* Styling is managed using Tailwind and shadcn/ui tokens
